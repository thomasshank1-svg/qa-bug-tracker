# BugLine

BugLine is a QA bug tracker demo for manual testing workflows. It records issues, areas, severity, reproduction steps, and verification status.

## Run

```sh
python3 server.py
```

Open `http://127.0.0.1:8109`.

## What it demonstrates

- Bug logging workflow
- Severity and status management
- SQLite issue storage
- Release QA tracking
- Local HTTP and domain tests
